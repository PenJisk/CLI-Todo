# A command line ToDo program written in C#

## Features
You can create tasks and list the created tasks, set and change status of a task - delete a specific task or clear all tasks in one go!  
  
you can fill:    
  
+ Task Priority  
+ Task title  
+ Task Description  
+ Task status  

### How to run
1.Download the latest version from **Releases**  
2.Unzip  
3.Execute **ToDoListConsole.exe**
